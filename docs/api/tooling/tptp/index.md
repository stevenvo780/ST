# `tooling/tptp/index.ts`

============================================================ TPTP — Barrel ============================================================ Parser + emitter para el formato TPTP (Thousands of Problems for Theorem Provers), soporte FOF / CNF / TFF light. Incluye un puente (`toFolProverFormat`) que convierte un `TptpProblem` al tipo `Formula` que entiende `src/fol-prover`.
