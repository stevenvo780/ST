# `proof-systems/proof-nets/index.ts`

============================================================ Proof Nets — Punto de entrada público ============================================================ Proof nets de Girard para MLL (Multiplicative Linear Logic):   - construcción a partir de un secuente,   - verificación de corrección (criterio Danos-Regnier),   - eliminación de cortes (axiom-cut y mult-cut). Diseño "didáctico" cercano al estándar de la literatura: nodos numerados, links {axiom, cut, tensor, par} con ports en orden canónico, conclusiones explícitas.
