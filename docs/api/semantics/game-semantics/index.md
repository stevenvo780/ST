============================================================ Game semantics IPC — Punto de entrada público ============================================================ Juegos dialógicos (Lorenzen-Felscher) para Intuitionistic Propositional Calculus. Una fórmula φ es válida en IPC sii el Proponente tiene estrategia ganadora en el juego dialógico sobre φ.
