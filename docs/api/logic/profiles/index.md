# `logic/profiles/index.ts`

============================================================ ST Profiles — Barrel de registro automático ============================================================ Este archivo importa y registra todos los perfiles built-in. Para añadir un nuevo perfil, simplemente impórtalo aquí y llama a registry.register(new MiPerfil()). Los perfiles externos pueden usar registerProfile() de la API pública sin modificar este archivo. ============================================================
