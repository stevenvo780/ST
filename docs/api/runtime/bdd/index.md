# `runtime/bdd/index.ts`

============================================================ ST BDD — Punto de entrada público ============================================================ Reduced Ordered Binary Decision Diagrams (ROBDDs) de Bryant (1986). API principal:   - `BDDManager(numVars)` crea un manager con orden por defecto 0..n-1.   - `variable(i)`, `not_`, `and_`, `or_`, `xor`, `implies`, `iff`, `ite`     construyen y combinan BDDs canónicos.   - `exists(v, b)`, `forall(v, b)` cuantifican.   - `satCount`, `isSatisfiable`, `isValid`, `equivalent`, `evaluate`     consultan.   - `fromCNF(clauses)` ingiere SAT en formato DIMACS.   - `fromFormula(ast)` ingiere árboles simbólicos. Garantías:   - Canonicidad estructural: dos BDDs equivalentes son la misma     referencia (apt para `equivalent` en O(1)).   - Apply algorithm con memoización: AND/OR/XOR en O(|G1|·|G2|).
